# VELOOP Rewards Website

A responsive React + Vite frontend demo for the VELOOP rewards/giveaway concept.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open this folder in VS Code.
4. In the terminal run:

   npm install
   npm run dev

5. Open the localhost address printed by Vite.

## Pages
Home, Rewards, Giveaways, Giveaway Details, Leaderboard, Earn Points, Winners, Profile, Help & FAQ, Login.

## Notes
- This is a frontend demonstration with sample content and demo interactions.
- The giveaway confirmation button does not submit a real entry or deduct points.
- Login/profile data is sample data. Real authentication, points ledger, giveaway entry records, winner management, and claim forms need a backend/API and database.
- Replace sample member names, prize data, dates, and point values before publishing.
